# DriveJob - Πλατφόρμα Σύνδεσης Οδηγών και Επιχειρήσεων

Το DriveJob είναι μια ολοκληρωμένη πλατφόρμα που συνδέει οδηγούς και επιχειρήσεις, επιτρέποντας στους οδηγούς να βρίσκουν εργασία και στις επιχειρήσεις να βρίσκουν κατάλληλους οδηγούς. Η πλατφόρμα χρησιμοποιεί προηγμένους αλγόριθμους ταιριάσματος για να προτείνει τις καλύτερες δυνατές συνδέσεις μεταξύ οδηγών και επιχειρήσεων.

## Χαρακτηριστικά

### Για Οδηγούς

- **Δημιουργία Προφίλ**: Οι οδηγοί μπορούν να δημιουργήσουν λεπτομερή προφίλ με τις άδειες οδήγησης, την εμπειρία, τις δεξιότητες και τις προτιμήσεις τους.
- **Αναζήτηση Αγγελιών**: Οι οδηγοί μπορούν να αναζητήσουν αγγελίες εργασίας με βάση διάφορα κριτήρια.
- **Δημιουργία Αγγελιών**: Οι οδηγοί μπορούν να δημιουργήσουν αγγελίες διαθεσιμότητας.
- **Προτάσεις Ταιριάσματος**: Οι οδηγοί λαμβάνουν προτάσεις για αγγελίες που ταιριάζουν με το προφίλ τους.
- **Αξιολογήσεις**: Οι οδηγοί μπορούν να αξιολογηθούν από τις επιχειρήσεις και να δουν τις αξιολογήσεις τους.

### Για Επιχειρήσεις

- **Δημιουργία Προφίλ**: Οι επιχειρήσεις μπορούν να δημιουργήσουν λεπτομερή προφίλ με πληροφορίες για την εταιρεία.
- **Αναζήτηση Οδηγών**: Οι επιχειρήσεις μπορούν να αναζητήσουν οδηγούς με βάση διάφορα κριτήρια.
- **Δημιουργία Αγγελιών**: Οι επιχειρήσεις μπορούν να δημιουργήσουν αγγελίες εργασίας.
- **Προτάσεις Ταιριάσματος**: Οι επιχειρήσεις λαμβάνουν προτάσεις για οδηγούς που ταιριάζουν με τις αγγελίες τους.
- **Αξιολογήσεις**: Οι επιχειρήσεις μπορούν να αξιολογηθούν από τους οδηγούς και να δουν τις αξιολογήσεις τους.

### Σύστημα Ταιριάσματος

- **Προηγμένος Αλγόριθμος**: Χρήση προηγμένου αλγορίθμου ταιριάσματος που λαμβάνει υπόψη πολλαπλά κριτήρια.
- **Προσαρμοζόμενα Βάρη**: Οι χρήστες μπορούν να προσαρμόσουν τα βάρη των διαφόρων κριτηρίων ταιριάσματος.
- **Ιστορικό Ταιριασμάτων**: Καταγραφή του ιστορικού ταιριασμάτων και των ενεργειών των χρηστών.

## Τεχνολογίες

- **Backend**: PHP 7.4+
- **Frontend**: HTML, CSS, JavaScript, Bootstrap
- **Βάση Δεδομένων**: MySQL
- **Web Server**: Apache
- **Αρχιτεκτονική**: MVC (Model-View-Controller)

## Εγκατάσταση

### Προαπαιτούμενα

- PHP 7.4 ή νεότερη έκδοση
- MySQL 5.7 ή νεότερη έκδοση
- Apache 2.4 ή νεότερη έκδοση
- Composer

### Βήματα Εγκατάστασης

1. **Κλωνοποίηση του αποθετηρίου**

   ```bash
   git clone https://github.com/yourusername/drivejob.git
   cd drivejob
   ```

2. **Εγκατάσταση των εξαρτήσεων**

   ```bash
   composer install
   ```

3. **Ρύθμιση της βάσης δεδομένων**

   - Δημιουργήστε μια νέα βάση δεδομένων MySQL
   - Αντιγράψτε το αρχείο `config/database.example.php` σε `config/database.php`
   - Ενημερώστε το αρχείο `config/database.php` με τις παραμέτρους σύνδεσης της βάσης δεδομένων

   ```php
   return new PDO(
       'mysql:host=localhost;dbname=drivejob;charset=utf8mb4',
       'username',
       'password',
       [PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION]
   );
   ```

4. **Εκτέλεση των migrations**

   ```bash
   php database/migrations/execute_migration.php
   php database/migrations/execute_matching_migrations.php
   ```

5. **Ρύθμιση του web server**

   - Ρυθμίστε το Apache να δείχνει στον φάκελο `public` του έργου
   - Βεβαιωθείτε ότι το mod_rewrite είναι ενεργοποιημένο

   Παράδειγμα ρύθμισης Apache:

   ```apache
   <VirtualHost *:80>
       ServerName drivejob.local
       DocumentRoot /path/to/drivejob/public
       
       <Directory /path/to/drivejob/public>
           AllowOverride All
           Require all granted
       </Directory>
   </VirtualHost>
   ```

6. **Προσθήκη στο hosts αρχείο**

   Προσθέστε την ακόλουθη γραμμή στο αρχείο hosts:

   ```
   127.0.0.1 drivejob.local
   ```

7. **Επανεκκίνηση του Apache**

   ```bash
   sudo service apache2 restart
   ```

8. **Πρόσβαση στην εφαρμογή**

   Ανοίξτε έναν περιηγητή και πλοηγηθείτε στη διεύθυνση `http://drivejob.local`

## Χρήση

### Εγγραφή και Σύνδεση

1. Επισκεφθείτε την αρχική σελίδα της εφαρμογής
2. Επιλέξτε "Εγγραφή" και συμπληρώστε τη φόρμα εγγραφής
3. Επιβεβαιώστε το email σας μέσω του συνδέσμου που θα λάβετε
4. Συνδεθείτε με τα στοιχεία σας

### Για Οδηγούς

1. **Δημιουργία Προφίλ**
   - Συμπληρώστε τα στοιχεία του προφίλ σας
   - Προσθέστε τις άδειες οδήγησης, την εμπειρία και τις δεξιότητές σας

2. **Αναζήτηση Αγγελιών**
   - Πλοηγηθείτε στην ενότητα "Αγγελίες"
   - Χρησιμοποιήστε τα φίλτρα για να περιορίσετε τα αποτελέσματα

3. **Δημιουργία Αγγελίας Διαθεσιμότητας**
   - Πλοηγηθείτε στην ενότητα "Οι Αγγελίες μου"
   - Επιλέξτε "Νέα Αγγελία" και συμπληρώστε τη φόρμα

4. **Προβολή Ταιριασμάτων**
   - Πλοηγηθείτε στην ενότητα "Ταιριάσματα"
   - Δείτε τις αγγελίες που ταιριάζουν με το προφίλ σας

### Για Επιχειρήσεις

1. **Δημιουργία Προφίλ**
   - Συμπληρώστε τα στοιχεία του προφίλ της εταιρείας σας

2. **Αναζήτηση Οδηγών**
   - Πλοηγηθείτε στην ενότητα "Οδηγοί"
   - Χρησιμοποιήστε τα φίλτρα για να περιορίσετε τα αποτελέσματα

3. **Δημιουργία Αγγελίας Εργασίας**
   - Πλοηγηθείτε στην ενότητα "Οι Αγγελίες μου"
   - Επιλέξτε "Νέα Αγγελία" και συμπληρώστε τη φόρμα

4. **Προβολή Ταιριασμάτων**
   - Πλοηγηθείτε στην ενότητα "Ταιριάσματα"
   - Δείτε τους οδηγούς που ταιριάζουν με τις αγγελίες σας
