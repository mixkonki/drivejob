# Temporary Test Files

Αυτός ο φάκελος περιέχει προσωρινά test files και diagnostic scripts που χρησιμοποιήθηκαν κατά την ανάπτυξη.

## Περιεχόμενα:

### Test Scripts:
- `test-*.php` - Διάφορα test scripts για debugging
- `check-*.php` - Scripts για έλεγχο λειτουργιών
- `fix-*.php` - Scripts για διόρθωση προβλημάτων

### Diagnostic Files:
- `comprehensive-diagnosis.php` - Εκτεταμένη διάγνωση συστήματος
- `simple-diagnosis.php` - Απλή διάγνωση
- `analyze-login-system.php` - Ανάλυση login system

### Log Files:
- `*.log` - Debug logs
- `*.txt` - Test reports
- `*.cache` - Cache files

## Σημείωση:
Αυτά τα αρχεία μπορούν να διαγραφούν με ασφάλεια μετά την ολοκλήρωση της ανάπτυξης.
