# Αναφορά Βελτίωσης Συστήματος Ταιριάσματος Αγγελιών

## Εισαγωγή

Το σύστημα ταιριάσματος αγγελιών είναι ένα κρίσιμο μέρος της πλατφόρμας DriveJob, καθώς επιτρέπει στους οδηγούς να βρίσκουν κατάλληλες θέσεις εργασίας και στις εταιρείες να βρίσκουν κατάλληλους οδηγούς. Αυτή η αναφορά παρουσιάζει προτάσεις για τη βελτίωση του αλγορίθμου ταιριάσματος αγγελιών, με στόχο την αύξηση της ακρίβειας και της αποτελεσματικότητας του συστήματος.

## Υπάρχουσα Κατάσταση

Αυτή τη στιγμή, το σύστημα ταιριάσματος αγγελιών χρησιμοποιεί τον `MatchingController` για να βρει ταιριάσματα μεταξύ αγγελιών εταιρειών και οδηγών. Ο αλγόριθμος βασίζεται σε βασικά κριτήρια όπως:

- Τοποθεσία
- Τύπος εργασίας
- Τύπος οχήματος
- Απαιτούμενες άδειες οδήγησης

Ωστόσο, ο αλγόριθμος δεν λαμβάνει υπόψη πιο εξειδικευμένα κριτήρια που θα μπορούσαν να βελτιώσουν την ποιότητα των ταιριασμάτων.

## Προτεινόμενες Βελτιώσεις

### 1. Προσθήκη Περισσότερων Κριτηρίων Ταιριάσματος

#### 1.1 Εμπειρία

- **Έτη εμπειρίας**: Ταίριασμα με βάση τα έτη εμπειρίας του οδηγού και τις απαιτήσεις της θέσης
- **Εμπειρία σε συγκεκριμένους τύπους οχημάτων**: Ταίριασμα με βάση την εμπειρία του οδηγού σε συγκεκριμένους τύπους οχημάτων
- **Εμπειρία σε συγκεκριμένους τύπους φορτίων**: Ταίριασμα με βάση την εμπειρία του οδηγού σε συγκεκριμένους τύπους φορτίων (π.χ. επικίνδυνα υλικά, ευπαθή προϊόντα)

#### 1.2 Δεξιότητες

- **Τεχνικές δεξιότητες**: Ταίριασμα με βάση τις τεχνικές δεξιότητες του οδηγού (π.χ. γνώση μηχανικής, χρήση ειδικού εξοπλισμού)
- **Γλωσσικές δεξιότητες**: Ταίριασμα με βάση τις γλωσσικές δεξιότητες του οδηγού (π.χ. για διεθνείς μεταφορές)
- **Επικοινωνιακές δεξιότητες**: Ταίριασμα με βάση τις επικοινωνιακές δεξιότητες του οδηγού (π.χ. για θέσεις που απαιτούν επαφή με πελάτες)

#### 1.3 Διαθεσιμότητα και Προτιμήσεις

- **Ωράριο εργασίας**: Ταίριασμα με βάση το προτιμώμενο ωράριο εργασίας του οδηγού και τις απαιτήσεις της θέσης
- **Διαθεσιμότητα για ταξίδια**: Ταίριασμα με βάση τη διαθεσιμότητα του οδηγού για ταξίδια και τις απαιτήσεις της θέσης
- **Προτιμώμενες διαδρομές**: Ταίριασμα με βάση τις προτιμώμενες διαδρομές του οδηγού και τις διαδρομές που προσφέρει η θέση

#### 1.4 Αξιολογήσεις και Αξιοπιστία

- **Βαθμολογία οδηγού**: Ταίριασμα με βάση τη βαθμολογία του οδηγού και τις απαιτήσεις της θέσης
- **Βαθμολογία εταιρείας**: Ταίριασμα με βάση τη βαθμολογία της εταιρείας και τις προτιμήσεις του οδηγού
- **Ιστορικό συνεργασίας**: Ταίριασμα με βάση το ιστορικό συνεργασίας μεταξύ οδηγού και εταιρείας

### 2. Χρήση Συντελεστών Βαρύτητας

Για να βελτιωθεί η ακρίβεια του αλγορίθμου, προτείνεται η χρήση συντελεστών βαρύτητας για τα διάφορα κριτήρια. Αυτό θα επιτρέψει στο σύστημα να δίνει μεγαλύτερη έμφαση σε κριτήρια που είναι πιο σημαντικά για τον οδηγό ή την εταιρεία.

#### 2.1 Προκαθορισμένοι Συντελεστές Βαρύτητας

- Τοποθεσία: 0.8
- Τύπος εργασίας: 0.7
- Τύπος οχήματος: 0.9
- Απαιτούμενες άδειες οδήγησης: 1.0 (απαραίτητο)
- Έτη εμπειρίας: 0.6
- Δεξιότητες: 0.5
- Ωράριο εργασίας: 0.4
- Βαθμολογία: 0.3

#### 2.2 Προσαρμοζόμενοι Συντελεστές Βαρύτητας

Επιπλέον, το σύστημα θα μπορούσε να επιτρέπει στους χρήστες (οδηγούς και εταιρείες) να προσαρμόζουν τους συντελεστές βαρύτητας με βάση τις προτιμήσεις τους. Για παράδειγμα:

- Ένας οδηγός θα μπορούσε να δώσει μεγαλύτερη βαρύτητα στο ωράριο εργασίας
- Μια εταιρεία θα μπορούσε να δώσει μεγαλύτερη βαρύτητα στην εμπειρία του οδηγού

### 3. Υλοποίηση Αλγορίθμου Μηχανικής Μάθησης

Για ακόμα καλύτερα αποτελέσματα, προτείνεται η υλοποίηση ενός αλγορίθμου μηχανικής μάθησης που θα μαθαίνει από τις προηγούμενες αλληλεπιδράσεις και θα βελτιώνει τα ταιριάσματα με την πάροδο του χρόνου.

#### 3.1 Συλλογή Δεδομένων

- Αποθήκευση των αλληλεπιδράσεων μεταξύ οδηγών και εταιρειών
- Αποθήκευση των αποδοχών και απορρίψεων προσφορών εργασίας
- Αποθήκευση των αξιολογήσεων μετά την ολοκλήρωση της εργασίας

#### 3.2 Εκπαίδευση Μοντέλου

- Χρήση αλγορίθμων όπως Collaborative Filtering ή Content-Based Filtering
- Εκπαίδευση του μοντέλου με βάση τα δεδομένα που έχουν συλλεχθεί
- Περιοδική επανεκπαίδευση του μοντέλου για βελτίωση των αποτελεσμάτων

#### 3.3 Προβλέψεις

- Χρήση του μοντέλου για την πρόβλεψη της πιθανότητας ταιριάσματος μεταξύ οδηγού και θέσης
- Ταξινόμηση των αποτελεσμάτων με βάση την πιθανότητα ταιριάσματος
- Παρουσίαση των καλύτερων ταιριασμάτων στους χρήστες

### 4. Βελτίωση του Περιβάλλοντος Χρήστη

#### 4.1 Φίλτρα Αναζήτησης

- Προσθήκη περισσότερων φίλτρων αναζήτησης για τους οδηγούς και τις εταιρείες
- Δυνατότητα αποθήκευσης προτιμήσεων αναζήτησης
- Δυνατότητα αποθήκευσης αγαπημένων αγγελιών

#### 4.2 Προτάσεις Ταιριάσματος

- Εμφάνιση προτάσεων ταιριάσματος στην αρχική σελίδα του χρήστη
- Αποστολή ειδοποιήσεων για νέα ταιριάσματα
- Εμφάνιση του ποσοστού ταιριάσματος για κάθε αγγελία

#### 4.3 Αναλυτικά Στοιχεία

- Εμφάνιση αναλυτικών στοιχείων για το γιατί μια αγγελία ταιριάζει με τον χρήστη
- Εμφάνιση προτάσεων για βελτίωση του προφίλ του χρήστη για καλύτερα ταιριάσματα
- Εμφάνιση στατιστικών για τα ταιριάσματα του χρήστη

### 2. Ενημέρωση του MatchingController

Ο `MatchingController` θα πρέπει να ενημερωθεί για να χρησιμοποιεί το `MatchingService`:

```php
namespace Drivejob\Controllers;

use Drivejob\Services\MatchingService;

class MatchingController extends BaseController
{
    private $matchingService;
    
    public function __construct()
    {
        parent::__construct();
        
        // Αρχικοποίηση του MatchingService
        $this->matchingService = new MatchingService(
            $this->jobListingRepository,
            $this->driversRepository,
            $this->companiesRepository,
            $this->driverLicenseRepository,
            $this->driverSkillsRepository
        );
    }
    
    public function driverMatches()
    {
        // Έλεγχος αν ο χρήστης είναι συνδεδεμένος ως οδηγός
        AuthMiddleware::hasRole('driver');
        
        // Λήψη του ID του οδηγού
        $driverId = Session::get('user_id');
        
        // Λήψη των κριτηρίων αναζήτησης
        $criteria = [
            'location' => $_GET['location'] ?? null,
            'job_type' => $_GET['job_type'] ?? null,
            'vehicle_type' => $_GET['vehicle_type'] ?? null,
            'sort_by' => $_GET['sort_by'] ?? 'match_score',
            'sort_direction' => $_GET['sort_direction'] ?? 'DESC'
        ];
        
        // Λήψη της τρέχουσας σελίδας και του ορίου
        $page = isset($_GET['page']) ? max(1, intval($_GET['page'])) : 1;
        $limit = isset($_GET['limit']) ? max(1, intval($_GET['limit'])) : 10;
        
        // Εύρεση ταιριασμάτων για τον οδηγό
        $result = $this->matchingService->findMatchesForDriver($driverId, $criteria, $page, $limit);
        
        // Φόρτωση του view

        include ROOT_DIR . '/src/Views/matching/driver-matches.php';
    }
```

### 3. Δημιουργία Νέων Πινάκων στη Βάση Δεδομένων

Για την υποστήριξη των νέων λειτουργιών, θα πρέπει να δημιουργηθούν νέοι πίνακες στη βάση δεδομένων:

#### 3.1 Πίνακας match_preferences

```sql
CREATE TABLE match_preferences (
    id INT AUTO_INCREMENT PRIMARY KEY,
    user_id INT NOT NULL,
    user_type ENUM('driver', 'company') NOT NULL,
    location_weight DECIMAL(3,2) DEFAULT 0.8,
    job_type_weight DECIMAL(3,2) DEFAULT 0.7,
    vehicle_type_weight DECIMAL(3,2) DEFAULT 0.9,
    license_weight DECIMAL(3,2) DEFAULT 1.0,
    experience_weight DECIMAL(3,2) DEFAULT 0.6,
    skills_weight DECIMAL(3,2) DEFAULT 0.5,
    schedule_weight DECIMAL(3,2) DEFAULT 0.4,
    rating_weight DECIMAL(3,2) DEFAULT 0.3,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    UNIQUE KEY unique_user (user_id, user_type)
);
```

#### 3.2 Πίνακας match_history

```sql
CREATE TABLE match_history (
    id INT AUTO_INCREMENT PRIMARY KEY,
    driver_id INT NOT NULL,
    job_listing_id INT NOT NULL,
    match_score DECIMAL(5,2) NOT NULL,
    driver_action ENUM('viewed', 'applied', 'rejected', 'no_action') DEFAULT 'no_action',
    company_action ENUM('viewed', 'accepted', 'rejected', 'no_action') DEFAULT 'no_action',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    UNIQUE KEY unique_match (driver_id, job_listing_id)
);
```

## Επόμενα Βήματα

1. **Υλοποίηση του MatchingService**: Δημιουργία του `MatchingService` με τις βασικές λειτουργίες ταιριάσματος
2. **Ενημέρωση του MatchingController**: Ενημέρωση του `MatchingController` για να χρησιμοποιεί το `MatchingService`
3. **Δημιουργία των νέων πινάκων**: Δημιουργία των πινάκων `match_preferences` και `match_history` στη βάση δεδομένων
4. **Υλοποίηση των νέων κριτηρίων ταιριάσματος**: Προσθήκη των νέων κριτηρίων ταιριάσματος στο `MatchingService`
5. **Υλοποίηση των συντελεστών βαρύτητας**: Προσθήκη της λογικής των συντελεστών βαρύτητας στο `MatchingService`
6. **Ενημέρωση του περιβάλλοντος χρήστη**: Προσθήκη των νέων φίλτρων αναζήτησης και των προτάσεων ταιριάσματος στο περιβάλλον χρήστη
7. **Δοκιμή και βελτιστοποίηση**: Δοκιμή του νέου αλγορίθμου ταιριάσματος και βελτιστοποίηση με βάση τα αποτελέσματα

## Συμπέρασμα

Η βελτίωση του αλγορίθμου ταιριάσματος αγγελιών θα αυξήσει σημαντικά την αξία της πλατφόρμας DriveJob, καθώς θα επιτρέψει στους οδηγούς να βρίσκουν πιο κατάλληλες θέσεις εργασίας και στις εταιρείες να βρίσκουν πιο κατάλληλους οδηγούς. Αυτό θα οδηγήσει σε αύξηση της ικανοποίησης των χρηστών και, κατά συνέπεια, σε αύξηση της χρήσης της πλατφόρμας.
