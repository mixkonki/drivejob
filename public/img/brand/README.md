# DriveJob — Brand Assets

Το λογότυπο DriveJob κρατά αυτούσιο το «DRIVE» του ομίλου Thessdrive (τιμόνι,
χέρια, πεντάλ) και αντικαθιστά τις σακούλες αγορών του DRIVE SHOP με
**χαρτοφύλακες εργασίας J-O-B** στα ίδια brand χρώματα.

## Χρώματα
| Χρώμα | HEX | Χρήση |
|---|---|---|
| Κόκκινο | `#ED1C24` | J — κύριο brand χρώμα |
| Πράσινο | `#39B54A` | O |
| Μπλε | `#0072BC` | B |
| Πορτοκαλί | `#F6891E` | εφεδρικό (από DRIVE SHOP) |
| Μαύρο | `#231F20` | γράμματα DRIVE |
| Κόκκινο UI | `#C62828` | header/κουμπιά site |

## Αρχεία
- `logo.png` + `logo-{1200,480,300,210,150}.png` — **κύριο**, για λευκό/ανοιχτό φόντο
- `logo-white.png` + παραλλαγές — DRIVE λευκό, χαρτοφύλακες έγχρωμοι (κόκκινο header)
- `logo-mono-white.png` / `logo-mono-black.png` — μονόχρωμες (knockout γράμματα), για
  watermark, εκτυπώσεις, σφραγίδες, μονόχρωμες επιφάνειες
- `icon-{512,192,180,64,32}.png` — τετράγωνο εικονίδιο (τιμόνι σε κόκκινο πλακίδιο)
- `icon-512-plain.png` — τιμόνι μαύρο, διαφανές φόντο
- `favicon.ico` — 16/32/48/64
- `og-image.jpg` — 1200×630 για κοινωνικά δίκτυα / προεπισκόπηση συνδέσμων

## Κανόνες χρήσης
- Ελεύθερος χώρος γύρω από το λογότυπο: τουλάχιστον όσο το ύψος ενός χαρτοφύλακα.
- Ελάχιστο πλάτος: 150px σε οθόνη, 30mm σε έντυπο.
- Μην αλλάζετε αναλογίες, χρώματα ή τη σειρά J-O-B.
- Σε κόκκινο/σκούρο φόντο χρησιμοποιείτε `logo-white` ή `logo-mono-white`.
